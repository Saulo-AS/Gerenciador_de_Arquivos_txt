# Gerenciador de Arquivos .txt

Programa em Python para gerenciar arquivos de texto (.txt) pelo terminal.

## Como Funciona

O projeto é dividido em 3 arquivos:

* **`main.py`**: Menu principal do programa (criar, editar, excluir, listar e sair).
* **`menus.py`**: Contém a função `mini_menu_edtArquivo`, que é um mini menu para a opção de editar (permite editar um existente ou criar um novo).
* **`arquivos.py`**: Contém as funções de manipulação dos arquivos (`cria_arquivo`, `edita_arquivo` e `deleta_arquivo`).

## Como Executar

```bash
python main.py
